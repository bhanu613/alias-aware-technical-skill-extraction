# AI-Use Disclosure Template — Complete Before Submission or Public Release

> This is a template, not a completed disclosure. Replace bracketed text with an accurate account of your own use of AI tools. Do not claim that an AI tool performed work you did not verify, and do not omit use that the University of Trier declaration requires you to disclose.

## Draft structure

```text
Tools used:
[List each generative-AI or coding-assistant tool used.]

Purpose of use:
[For example: brainstorming, wording revision, code explanation, debugging support, layout planning, or other permitted assistance.]

Human responsibility and verification:
[I independently selected the research question, made methodological decisions, performed annotation, executed the code, reviewed all outputs, verified the final metrics, and take responsibility for the submitted work.]

Use in the final project:
[State which artefacts, if any, were drafted with assistance and how they were reviewed or revised.]
```

## Required final check

Compare the completed disclosure with the current official University of Trier academic-integrity declaration and course instructions. The signed official declaration belongs in the separate appendix PDF, not in this repository unless you intentionally choose to publish it.
